# Data attribution

Reference transcriptions in completed speech run files originate from
`google/WaxalNLP`, Yoruba / Media Trust subset, pinned revision
`5f4d8ca24f2b9d168b2ee545f1febaaff4b40580`.

The dataset card assigns **CC-BY-SA-4.0** to Media Trust data. This code repository's
MIT license does not relicense those reference texts. Attribute the original
dataset and provider when redistributing reference-containing result files:

- [Google / WAXAL dataset](https://huggingface.co/datasets/google/WaxalNLP)
- [WAXAL paper](https://arxiv.org/pdf/2602.02734)
- [CC-BY-SA-4.0](https://creativecommons.org/licenses/by-sa/4.0/)

Original audio is not committed. Prediction text is experimental ASR output,
not a validated transcript or a claim of language competence.
